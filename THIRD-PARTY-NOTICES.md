# Third-party notices

Chronicle bundles a small amount of third-party material. Everything else is
pulled from npm at install time and keeps its own license inside `node_modules`.

Licensed under the SIL Open Font License, Version 1.1. The full text is kept next
to the font files in `packages/template-astro/public/fonts/OFL.txt`.

## Generated assets

The Open Graph defaults, favicons and `site.webmanifest` are generated by
`scripts/brand-assets.mjs` from the site name, description and accent colour.
They contain no third-party artwork.

## Runtime and build dependencies

Astro, Marp Core, KaTeX, Mermaid, markdown-it, highlight.js, DOMPurify, jsdom,
sharp, Vue and the other packages listed in the `package.json` files are
distributed under their own licenses (MIT, ISC, Apache-2.0, BSD and SIL OFL).
Run `npm ls --all` for the exact tree, or inspect each package's `LICENSE` file
in `node_modules`.
